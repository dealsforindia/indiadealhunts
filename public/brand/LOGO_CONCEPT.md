# IndiaDealHunts logo concept 01

Created with the built-in image generation tool. Original source image retained; no existing assets replaced.

Asset: `indiadealhunts-3d-v1.png`, transparent PNG. Preview: `/logo-preview.html`.

The preview uses CSS perspective and pointer tilt on a raster image. It is not a Three.js mesh and cannot show the unseen back of the emblem. Motion is disabled for reduced-motion preferences and devices without a fine hover pointer. No WebGL dependency was added to the storefront.

## Generation prompt

Use case: logo-brand. Create a single premium 3D logo emblem for IndiaDealHunts, an Indian shopping deal discovery brand whose site uses vivid royal blue, white and midnight navy. Asset: isolated symbol with genuine transparent background, usable as website brand icon. Subject: an original compact sculptural price-tag silhouette, rounded-square diagonal tag body with a bold lightning bolt cutout through its center, clever negative space, small neatly integrated circular tag hole in upper corner. Simple iconic geometry that reads at small sizes, not a detailed illustration. Material: deep electric royal-blue enamel on the front face, precision-machined brushed silver side edges, restrained glassy highlights, dimensional beveled extrusion. Near-front three-quarter camera angle, only slight tilt, centered with generous transparent margins. Lighting: soft polished studio highlights, crisp silhouette. Sophisticated and trustworthy, not a gaming badge or cryptocurrency coin. No text, no lettering, no rupee symbol, no background, no floor, no large drop shadow, no sparks, no decorative objects, no watermark. One emblem only. Beautiful professionally art-directed product-render quality with clean geometry.

## Production direction

Use a small optimized static mark in navigation and favicons. If a real rotating 3D model is added, load its renderer on demand in a hero-sized area, retain the static mark as fallback, cap rendering resolution and stop rendering when hidden. Never require a working GPU to access shopping features.
