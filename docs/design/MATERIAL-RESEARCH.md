# Material research — 2026-10-30

## Diagnosis
Generated mockup rejected: conventional catalogue composition, unrequested delivery selector, invented counts/review claims, excessive outlines. It did not demonstrate the optical and compositional qualities requested. Do not use it as implementation authority.

## Primary sources inspected as text/code, not verified playback
- Apple Meet Liquid Glass: https://developer.apple.com/videos/play/wwdc2025/219/ — describes controls/navigation as a separate floating layer; expanding controls change apparent thickness, shadow and refraction. Apply to navigation/menu continuity, not every product card.
- Paper Fluted Glass: https://shaders.paper.design/fluted-glass — exposes distortion, highlights/shadows, edge strength, blur and independent grain controls. Useful texture benchmark for a small decorative price-range area. Its image input is not automatic refraction of arbitrary live DOM.
- Paper shader catalogue: https://shaders.paper.design/ — liquid metal, lens distortion, grain and image filters. Candidate mechanisms only; no new dependency selected.
- Codrops multiside refraction: https://tympanus.net/codrops/2019/10/29/real-time-multiside-refraction-in-three-steps/ — reference for actual Three.js optical treatment; a scene technique, not a universal HTML glass-button solution.
- Linear refresh: https://linear.app/now/behind-the-latest-design-refresh — reduce competing chrome; make structure quieter than the task content. This is hierarchy, not a mandate for minimalism.

## Proposed implementation study
Build one coded study containing the same control over a detailed background, with clear/smoked/frosted material options and light/dark switches. Include a menu opening from its trigger, press/hover/focus states, one real-data price graph and an opaque product surface. Show the actual browser output rather than generated marketing imagery.

Evaluate rim geometry, optical distortion (if implemented), readability, surface separation, mobile input and rendering cost before applying globally. Existing CSS pass is a baseline approximation; true refraction remains unimplemented. Do not claim playback/FPS/browser verification without evidence.

## Direction
Charcoal content planes, selective emerald/yellow data colour, one continuous textured background, unequal panel sizes and lighter numeric typography. Concentrate optical effects in navigation/contextual controls. No fake badges/counts/history. Do not add location, delivery or unrelated shopping workflows.
